THE THEOREM BEING CHECKED

Every nontrivial zeta zero has real part ½.

ζ(s) = 0, s ∉ {−2, −4, −6, …}, s ≠ 1 ⇒ Re(s) = ½

Here s is a complex number. The negative even integers are the trivial zeros; s = 1 is excluded. The claim concerns every other zero, at any height.

Exact Lean statement
theorem riemannHypothesis : RiemannHypothesis := rhOfAll

-- RiemannHypothesis in the pinned mathlib:
∀ (s : ℂ) (_ : riemannZeta s = 0)
  (_ : ¬∃ n : ℕ, s = -2 * (n + 1)) (_ : s ≠ 1),
  s.re = 1 / 2

Verify the proof

Archive certificateTo be uploadedDownload certificate

The checker uses Python 3.10 or later with no Python packages to install. Use macOS, Linux, or Ubuntu under WSL on Windows. On macOS, install the Apple command line tools with xcode-select --install if prompted.

The first full run needs internet access and a writable folder. The extracted source alone takes about 1 GB. The Lean toolchain, mathlib, and build files need additional space, and the typecheck can take a long time.

Download verify_proof.pyStandalone proof checker Download Lean sourcesPinned project and proof source

Open a terminal in the folder containing the script. Preview the steps, or run the full check.

Preview the steps
python3 verify_proof.py --plan
Run the full check
python3 verify_proof.py

The checker finds lean-sources.tar.gz in the current folder or beside the script, and downloads the source if neither copy is present. Use --archive "/path/to/lean-sources.tar.gz" to choose an archive explicitly.

Rerun the same command to resume an interrupted build. Use --work-dir to select a different destination or --stats-only to check the source fingerprint and configuration without starting Lean.

Results, logs, and certificate.json are written to riemann-independent-check/results/ by default. The certificate reports the run status and records the exported theorems’ axioms after a successful typecheck.

Recompute the statistics

The statistics script runs with Python 3.10 or later on Linux, macOS, and Windows. It reads a Lean or TXT archive directly and writes counts, a source fingerprint, and dependency layers to JSON.

Download proof_stats.pyStandalone statistics script Download TXT sourcesPlain-text copy of the source tree 
python3 proof_stats.py txt-sources.tar.gz --output statistics.json

Substitute lean-sources.tar.gz or the path to an extracted source folder as needed. In a native Windows terminal, use py -3 in place of python3 if that is how you launch Python.
